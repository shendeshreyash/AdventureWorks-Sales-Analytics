# AdventureWorks Sales Analytics

Data Analyst internship project analyzing the AdventureWorks relational 
sales database, covering sales performance, customer behavior, and 
product-level KPIs.

## Project Overview
Completed as part of a Data Analyst internship at AI Variant. Involved 
writing SQL joins and aggregations across AdventureWorks' fact and 
dimension tables, then building interactive dashboards to present 
sales, customer, and product insights.

## Tools Used
- **SQL (MySQL)** — Multi-table joins, date transformations, calculated fields
- **Excel** — KPI reporting and pivot analysis
- **Tableau** — Interactive sales dashboards
- **Power BI** — DAX-driven reports and visualizations

## Data Model
Joined `sales_combined` (fact table) with `dimproduct`, `dimcustomer`, 
and `dimsalesterritory` to compute Sales Amount, Production Cost, and 
Profit per transaction, broken down by year, quarter, month, customer, 
product, and territory.

## Folder Structure
- `/Excel` — KPI workbook (Q0–Q13)
- `/SQL` — Core query joining sales, product, customer, and territory data
- `/Tableau` — Tableau packaged workbook (.twbx)
- `/PowerBI` — Power BI report file (.pbix)
- `/Presentation` — Final project report
